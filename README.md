Entry for the make.fun competition **"Unsent: The Micro-Confession Sprint"**. The program writes one two-part micro-confession — a `To:` line and the unsent line itself (141 characters) — to `/output/entry.txt`:

> To: Mr. Alvarez, my high school janitor
> I was the one who broke the trophy case in 2011. You got blamed and I watched you clean it up anyway.

The line was chosen by manual ranking of 12 candidates against the kit's judge brief, in its stated order (see `candidates.md`): two-part form, a felt reason it stayed in drafts, a `To:` line the message cannot live without, and a voice that reads as typed and never sent.

## Run it

```bash
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To choose another directory, set `MAKEFUN_OUTPUT_DIR`:

```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

No dependencies beyond Python 3.13's standard library, and no network access.
